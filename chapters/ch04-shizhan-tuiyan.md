# Chapter 4: 实战推演——评改案例里的成稿轨迹

## Core Idea
何剑文实战篇用十余篇真实稿子的评改，演示"自下而上归类概括"的完整操作；再用五篇自己不同年份的同类文稿，呈现一个基层笔杆子的进阶轨迹。方法看一遍不如跟着改一遍。

## Frameworks Introduced
- **自下而上归类概括**（6.1–6.12 演示的标准流程）：
  1. 找料子：逐段压缩为短语
  2. 梳辫子：按共性归堆，连点成线，必要时二次归类
  3. 戴帽子：为每堆起标题，形成新结构
  4. 检验：新结构是否覆盖原稿全部信息点
- **进阶轨迹自评法**（第7章）：把同一文种不同年份的稿子并排点评，看结构、标题、语言三方面的变化，就是自己的成长记录
- **申论迁移**（第8章）："五子棋"直接用于申论：理解"来料加工"（给定的材料即"材"），下好五子棋拿结构分

## Key Concepts
- **合并同类项**：梳辫子的具体手法，同因、同果、同类的段落归一
- **二次归类**：第一次归堆结果仍杂乱时，按更大主题再归一次
- **点评维度**：结构（逻辑通不通）、标题（对不对得上）、语言（实不实）

## Mental Models
- 修改别人的稿子是学写作最快的方式：毛病看得见，方法才落得下
- 同题重写：拿旧题目按新方法再写一遍，对比出方法的价值

## Anti-patterns
- **先框架后素材**：案例里多数原稿的毛病正是"先定了三三制框架"，内容塞不进去只能注水
- **只点评不重写**：看出问题不等于能改对，必须动手重排

## Worked Example
6.1 评改《××市围绕"三自一化"提升社区党建活动效果》：原稿按"自主培训/自主设计/自主实施"三条展开，每条里既有全市做法又有具体社区案例（如胜利社区请退休党员讲书法绘画课、富强区文明社区党委搞"弘扬红船精神"楼院党课宣讲30余次）。评改第一步在每条后括注短语（"利用社区志愿者师资开展培训"等），即找料子；第二步发现三条料子共性是"提能力、增活力、促规范"，据此重排；第三步给每堆戴帽。整个演示画出"思维导图"，读者可逐步验证每一步的取舍。第7章又将作者2017/2018/2019三年抓基层党建述职报告并排点评，让读者看到同一个人用同一方法三年后的结构差异。

## Key Takeaways
1. 评改流程四步：找料子→归堆→戴帽→验证覆盖
2. 归类概括的关键动作是"在段落后写短语"，写不出短语说明该段无观点
3. 存下自己历年的同类稿子，定期并排重读
4. 方法可迁移：总结、信息、申论同源
