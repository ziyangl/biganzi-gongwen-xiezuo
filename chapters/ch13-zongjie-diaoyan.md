# Chapter 13: 总结·汇报·调研·整改——实务文种结构

## Core Idea
总结、汇报、调研报告、剖析整改是覆盖面最广的实务文种。共同基因是"情况—问题—对策"三分结构，差异在角度：向谁汇报、站在谁的立场、达到什么目的。

## Frameworks Introduced
- **总结类**（王振第5章+笔杆子2第三十三章）：主体角度四级递进——个人总结→科室总结→单位总结→综合性总结报告（政府工作报告级），角度越远站位越高；结构为帽段（总体概括）→主要工作（做法+成效分条）→问题不足→下步打算
- **"做法+成效"标题公式**（李永新）：每条工作用"举措+效果"双要素概括——做法给可操作性，成效给说服力
- **汇报材料**（笔杆子2第二十六章）：听众是"更大的东家"，研究听者甚至比研究讲者更重要；结构常为工作推进情况→成效亮点→困难问题→需要支持事项
- **调研课题类**（王振第6章）：选题（真问题）→调查（多渠道占料）→研究（分析提炼）→成文（情况+分析+建议）
- **剖析整改类**（王振第7章）：问题清单（具体化、可核查）→原因剖析（主观为主、挖到根上）→整改措施（对应问题逐条可销号）
- **角度与亮点**（王振第3、4章）：同一件事角度不同结论不同（甲县乙县党校互访各写各的角度）；亮点是让人眼前一亮的元素，发现亮点→布置亮点→展示亮点是新手进阶的分水岭

## Key Concepts
- **帽段**：总结开头对全年工作的总体概括，定全文基调，地位极重
- **问题与对策一一对应**：调研/整改材料中，第N个问题对应第N条对策，读者可逐项核对
- **亮点密度**：一份材料一两处真亮点足以支撑价值；平淡无奇的全面铺陈等于白写

## Mental Models
- 总结是给未来的自己看的弹药库：今年的问题梳理就是明年的工作思路
- 汇报的本质是"让听者做决策"：不是展示干了多少，是帮助听者抓住要害

## Anti-patterns
- **总结写成流水账**：按时间罗列动作，无归类无提炼（正确做法是"合并同类项+做法成效"双要素）
- **问题部分虚化**：问题写成"有待进一步提高"，剖析不到根，整改无从落地
- **角度错位**：科室向局领导汇报时把重点放在部门联动（那是县领导层面的对策），应先讲清自身举措与发现

## Worked Example
农贸市场巡查的"一料三写"（王振第6章案例）：某县市场监管局科室完成农贸市场专题巡查后写三份材料。第一份（向局领导汇报）：一、专题巡查工作情况（突出重点任务/优化时序安排/做好后勤保障——展示科室执行力）；二、运行情况与问题（规划布局有待优化/改造升级滞后/投入机制不完善/监管力量薄弱）；三、对策建议（对接资规单位优化布局/协调住建加快改造/争取财政支持/强化科室力量）。第二份升级为向县领导汇报：角度从"我们科做了什么"切换为"全县层面的形势与建议"，弱化科室动作、强化宏观对策（"上级逼着干"变"主动谋划"的站位差异）。第三份可再转为调研通报。同一素材，三种角度——这就是"站在什么样的立场说话"的实操。

## Key Takeaways
1. 总结先定主体角度（个人/科室/单位/综合），角度决定取舍
2. 每条工作过"做法+成效"双要素检验，只有做法无成效的降格并入
3. 问题与对策逐条对齐编号，可核查可销号
4. 汇报材料先研究听者要什么，再决定亮什么、藏什么、要什么
