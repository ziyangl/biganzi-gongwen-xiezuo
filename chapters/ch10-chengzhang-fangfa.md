# Chapter 10: 成长方法论——段位、素养与刻意练习

## Core Idea
写作没有捷径，只能按段位渐进：像（1.0）→顺（2.0）→是（3.0）→通（4.0）。每个段位有明确的达标特征，刻意练习的要点是把一篇合适的材料写许多遍，而不是匆匆忙忙写很多篇。

## Frameworks Introduced
- **笔杆子"4个段位"**（薛贵辉精进）：
  - 1.0 写得"像"：文种选择、字体字号、版式符合 GB/T 9704—2012，看得出"三分样"
  - 2.0 写得"顺"：逻辑通、气脉顺、读来不卡
  - 3.0 写得"是"：内容准确、写什么像什么，切中工作实质
  - 4.0 写得"通"：通权达变，应对人/文/事/地/时5大变量的柔性写作
  - When to use: 定期自评，确认当前段位与下一步练什么
- **精准练习**（何剑文）：把一篇合适的材料写许多遍——用20%的时间掌握一个领域80%的内容；练习对象选本单位高频文种
- **写作力"6项修炼"**（36堂课第26课）：写作力是多种能力的化合物，单项突破无效
- **复盘体系**（36堂课第30课）：6种形式（全面/专项等）× 6个对象 × 5种方法；写前有"沙盘"，写后有复盘
- **成长路径配套**：7种素养、精神世界与精神内耗的治理、10个高效写作习惯、从曾国藩等历史人物身上学写作功夫（日课与恒心）
- **一稿多磨**：工作报告类年度文稿连续两年复盘对比（36堂课第32课）——定准"调子"方能弹准"曲子"、搭稳"架子"方能装实"里子"、擦亮"套子"方能美化"面子"

## Key Concepts
- **写得"像"是态度问题**：半年可入门；写不像的大概率是从不看标准与范文
- **"三手"现象**：轻易不沾手 → 沾手上不了手 → 上手脱不了手；破解靠段位认知加精准练习
- **写作函数的柔性化**：4.0段位的标志是换变量不慌——换领导、换文种、换领域都能快速重定参数

## Mental Models
- 成长如物种演化，阶段不能跨越也不能省略（马特·里德利《自下而上》）
- 在写作中学习写作："从战争学习战争"是主要方法

## Anti-patterns
- **以量代质**：写一百篇平庸稿不如把一篇好题目改十遍
- **跳段位练花活**：没写像就追文采，结构地基不稳
- **只苦熬不复盘**：苦劳堆不出段位，复盘才是升级通道

## Worked Example
4个段位自评对照（按薛贵辉的检验标准改写成自查表）：拿一份自己写的请示——文种对不对（把"请示"写成"报告"即未入门）、格式按国标吗（字体字号行间距）→ 达标则 1.0。把稿子读出声——卡顿、绕口、断气处即逻辑毛刺 → 排掉则 2.0。把稿子给业务科室看——说的和工作实情对得上吗、问题找得准吗 → 对上则 3.0。换个场景推演——同一件事改写成汇报、改写成简报、换位到上级口吻，都能快速重构 → 可则 4.0。定位后，练习就瞄准下一个段位的短板动作。

## Key Takeaways
1. 每半年用四段位标准给自己定位，练缺什么
2. 精准练习选本单位最高频文种，一篇多改
3. 复盘固定化：写前沙盘推演，写后按对象分项复盘
4. 4.0 段位的标志是柔性：变量变了能快速重定参数
