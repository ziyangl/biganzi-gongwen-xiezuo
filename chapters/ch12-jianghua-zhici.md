# Chapter 12: 讲话稿与致辞——三段式与场合适配

## Core Idea
讲话稿是公文里"人"的因素最重的文种：8分共性技法+2分讲者个性。部署动员类讲话有稳定的"为什么干—干什么—怎么干"三段论，致辞类则要应景、口语化、有味道。

## Frameworks Introduced
- **部署动员讲话三段式**（笔杆子2第十八章）：
  - 第一部分讲道理：为什么干——正面讲背景意义必要性，或反面讲不干的危害，结合时限讲紧迫性
  - 第二部分讲内容：干什么——面面俱到反而"胡子眉毛一把抓"，突出重点难点让与会者抓住关键
  - 第三部分讲方法：怎么干——加强组织领导、明确责任、加强宣传、强化督查问效
  - 收尾：鼓舞士气、发出号召
- **帽段套件**（开场固定句式）："今天，我们召开××动员会，主要任务是深入贯彻××精神，认真落实××，安排部署××工作。刚才，××同志作了安排，××作了表态发言，讲得都很好，关键是要抓好落实。下面我讲几点意见。"
- **"为什么干"标题套件**：统一思想提高站位 / 提高政治站位，深刻认识开展××的重要意义 / 切实增强紧迫感责任感
- **应景讲话5特点6诀窍**（36堂课第34课）：篇幅短、便于口头表达、特定情境、易出彩、写法灵活；诀窍——结构尽量简单、对嵌套说"不"、有观点有味道、"口感"要好、打感情牌、应景
- **传达提纲/主持词/述职/致辞/任职离任**（笔杆子2各章）：同属"讲话族"，各有共性模板+套件
- **致谢词比较法**（王振）：好的致谢照顾到上级领导、相关部门、社会各界与一线干部，且体现领导对工作的熟悉——谢谁、谢什么、按什么顺序谢

## Key Concepts
- **8/2法则**：80%精力研究通用讲话技法（锤炼领导共性思维），20%研究讲者本人特点
- **口感与耳感**：讲话稿是写来"讲"的，句子要短、口语化，让读的人顺口、听的人入耳
- **场合适配**：动员会要燃、汇报会要实、致辞要雅、座谈会要亲

## Mental Models
- 讲话稿是替人说话：先进入讲者角色（找到"当他的感觉"），再组织语言
- 三段式的本质是说服链：讲通思想→讲明任务→讲清路径，缺一段听众就跟丢一段

## Anti-patterns
- **第二部分面面俱到**：工作部署贪多求全，重点被稀释
- **书面语上口**：长句、嵌套、生僻词是讲话稿大敌（"对嵌套说不"）
- **千人一稿**：换领导不改风格参数，稿子永远过不了

## Worked Example
动员讲话帽段+骨架套写（按笔杆子2共性模板）：标题《在全市××工作动员大会上的讲话》，落款注明职务姓名与日期；开场即帽段（贯彻精神+部署任务+肯定表态发言）；主体三部分——"一、提高政治站位，深刻认识开展××工作的重要意义"（为什么干，正反结合讲紧迫性）"二、聚焦重点任务，全力抓好××各项工作的落地落实"（干什么，点出重点难点）"三、强化组织保障，确保××工作取得实效"（怎么干：组织领导、责任分工、宣传引导、督查问效）；结尾"同志们，开展××工作，责任重大，任务艰巨，我们要……"发出号召。全程句子短段落短，每部分二至三个层次，供口头展开。

## Key Takeaways
1. 动员类讲话先套三段论，再往里填本地本校 hype 细节
2. 写完必做"读出声"测试：卡壳处即需要改短处
3. 研究讲者：花脸稿与历史讲话是最好的风格教材
4. 致辞应景的诀窍是"借现场"：借场合、借天气、借共同记忆入题
