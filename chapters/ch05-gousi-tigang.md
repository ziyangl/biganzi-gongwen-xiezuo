# Chapter 5: 构思与提纲——谋篇布局的技术

## Core Idea
"后期修改时所加的班，都是写提纲时偷的懒"（薛贵辉）。提纲是把看不见的灵感凝固成看得见的文字，无提纲不写作。

## Frameworks Introduced
- **谋篇布局五步**（32讲第13讲"隆中对"）：
  1. 定主题：4种定法——摆目标、明理念、提要求、列措施
  2. 选结构：横式/纵式/总分，并理清各自的逻辑关系（时间、空间、事理；整体与局部、概括与分析、本质与现象）
  3. 拓思路：分类（横向切类型）、分块（切组成板块）、分层（纵向切层次）——划分越细理解越深
  4. 列提纲：三级形态——概念型（粗线条，四梁八柱）/ 标题型（细化到标题与篇幅）/ 方案型（到分工与时间，用于大稿团队作业）
  5. 配素材：摸排存量、判断量与质（真实性/典型性/新颖性/实用性）、在提纲下标注每部分用什么素材
- **提纲"八段锦"**（32讲第15讲，8个环环相扣动作）：定调子→搭架子→填肚子→梳辫子→美面子→摆棋子→开方子→变样子
- **6种谋略**（32讲第18讲）：谋"道"（规律与全局）居首，先跳出文稿看文稿再动笔

## Key Concepts
- **概念型提纲**：诸葛亮"隆中对"即此类——目标（兴复汉室）+ 分解（跨有荆益、西和诸戎、南抚夷越、外结好孙权、内修政理）
- **细目式提纲**：不只写要点，还写篇章安排（从哪说起、怎么过渡、如何收束），初学者首选
- **提纲即规划性文本**：对写作有规范、指导作用，防"挤牙膏"式写作

## Mental Models
- 提纲是设计图纸：没有图纸，技艺再精湛也会把房子盖砸
- "袖手于前，始能疾书于后"：想得清楚才写得明白，前期慢就是后期快

## Anti-patterns
- **不列提纲跟着感觉走**：从主标题开始一行行往屏幕上码，写着写着进死胡同
- **提纲只列一级标题**：标题下写什么没想清楚，动笔即卡壳
- **配素材被跳过**：提纲完不摸素材底，写到一半发现无米下锅，被迫改提纲

## Worked Example
某报告提纲在标题里定调子：《决胜全面建成小康社会 夺取新时代中国特色社会主义伟大胜利》——"全面建成小康社会"是摆目标定主题。对比《稳增长 调结构 促融合 奋力推进全省工业和信息化转型升级》——三个短句（措施型）定主题。同一动作（定主题），两种参数：目标型适合愿景类文稿，措施型适合工作部署类。迁移到自己写汇报：先判断该用哪种定法，再走五步。

## Key Takeaways
1. 提纲至少细化到二级标题并标注素材来源，才算可用
2. 大稿（政府工作报告类）必须做到方案型提纲才能分工
3. 拓思路用三分法：类别、板块、层次至少切一轮再写
4. 提纲八段锦中"美面子"（打磨标题）在成文前做，省一次全文返工
