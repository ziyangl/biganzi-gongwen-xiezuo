# Chapter 3: 思维方法——归纳、演绎与"五子棋"

## Core Idea
"写不明白是因为想不明白，想不明白是因为逻辑混乱"（何剑文）。写作 = 网状思考 → 树状结构 → 线性表达（平克），对应五子棋写作法：找料子、梳辫子（构思）→ 戴帽子、填肚子、理面子（表达）。

## Frameworks Introduced
- **"五子棋"写作法**（何剑文）：
  - 找料子：用一句话/一个短语概括某项工作。两法——①找关键词（简单内容抓重点字眼）②"做法+成效"（复杂工作问"做了什么""为什么做"）
  - 梳辫子：归类分组，在做法和成效上找共性，搭建树状结构
  - 戴帽子：提炼标题（规定动作求完整，创新动作求亮点）
  - 填肚子：填充内容，线性表达
  - 理面子：修改美容
  - When to use: 任何材料从构思到成稿的全过程，尤其适合入门者
- **归纳法**：结构化思考的工具，"化石成金的炼金术"——把碎片化、低价值信息整合为结构化、高价值文章（去伪存真、去粗取精、由此及彼、由表及里）
- **演绎法**：因果性表达的工具，自上而下——先结论后论据
- **MECE法则**：归类分组时相互独立、完全穷尽，防重叠防遗漏
- **公文写作9大思维**（薛贵辉）：用户、相对、系统、跨界、故事、数学、逻辑、模仿、战略。核心两条：用户思维（"不是你想写什么，是别人想说什么、想听什么"——只顾自己表达是在写日记）；相对思维（文无定法，方法随场合变）

## Key Concepts
- **"材"与"料"的区别**：原始信息是"材"（如木材），加工后才是"料"（木料），"材"不能直接进稿
- **结构化思考 vs 因果性表达**：前者用归纳，后者用演绎，多数公文两部分兼有
- **金字塔体系**：主标题层层细化衍生出的观点树

## Mental Models
- 把写材料当"碎片整理"：素材堆是网状的，稿件是树状的，成文是线状的
- 写作函数思维：同一工作，总结里讲成效、请示里讲困难、讲话里讲意义——素材相同，加工不同

## Anti-patterns
- **"材"当"料"用**：简讯、信息原文直接进稿，字数虚、观点散
- **归类不穷尽**：三级标题拼起来盖不住二级标题，遗漏自然发生
- **找料子太空泛**：料子空，梳辫子就无从下手

## Worked Example
《××社区工作总结》评改：原稿一条段——"注重党委成员责任分工落实和素质能力提升。自社区党委选举换届以来，坚持以基层党建促进能力提升。完成新一届选举工作，顺利选出党代表20名……"。第一步找料子：抓关键词"新的党委班子成员"，概括为"抓社区班子建设"；复杂段落则拆"做法（明确分工、责任落实）+成效（班子结构合理）"。第二步梳辫子：把全部段落各找料子后，按共性归堆成几大类。第三步戴帽子：每类起一个完整标题。何剑文用这个案例演示"四梁八柱"如何从素材里长出来，而不是先想好框架再填。

## Key Takeaways
1. 先找料子再归类，不要从框架倒推内容
2. 一句话说不清某段工作在干什么，说明还没想清楚
3. 检验分组：标题之间互斥、合起来穷尽
4. 用户思维是九大思维之首：动笔前先答"读者是谁、他关心什么"
