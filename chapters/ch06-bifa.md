# Chapter 6: 笔法——开头、衔接、踩点与写实

## Core Idea
好开头是"钩子"，好衔接靠"榫卯"，好内容要"踩点"。笔法是把想清楚的东西写得让人读得进去的工艺。

## Frameworks Introduced
- **开头引题17法**（32讲第19讲）：讲述背景、论述意义、阐明目的、列举依据、讲明道理、抒发情感、设置疑问、讲述故事、亮出态度、归纳概括、明确目标、叙述过程、总结评价、借题发挥、查摆问题、定义概念、交流感受
  - When to use: 全文、部分、段落三级引题都适用（引题不只在文章开头）
  - How: 按文稿类型选——总结类开头用"亮出态度"，计划类段落开头用"明确目标"，理论文章/致辞用"借题发挥"，自查整改类用"查摆问题"
- **直笔与曲笔**（审问"曲直"）：直笔单刀直入、首句破题；曲笔迂回铺垫。公文一般倡导直笔
- **内容"黏合术"10种**（32讲第20讲）：起承转合之间的衔接技术，防"过片断曲意"
- **写通顺的9条逻辑**（32讲第21讲）：时间、空间、事理、体例、推理、总分、矛盾、因果、并列——逻辑通则经络通
- **踩点8法**（32讲第23讲）：Why（为什么写）、What（写的什么事）、Where（何种场合）、Who（何人讲何人听）等维度先对齐再落笔
- **写实的5招**（32讲第24讲）：讲通俗话不讲晦涩话、讲真心话不讲虚假话、讲简单话不讲复杂话等；主题集中、思路清晰、观点系统

## Key Concepts
- **引题3种类型**：引导全篇 / 引导多个段落 / 引导一个段落——段首句也是引题
- **引题5个作用**：交代背景、说明原因、烘托气氛、揭示意义、引领阅读

## Mental Models
- 开头是风景区大门，也是每个小景点的路标：不是只有文章第一段需要"开好头"
- 段落开头同样定调：读者往往只读各级标题和段首句，这些位置决定稿子的"第一印象"

## Anti-patterns
- **开头绕远**：铺垫过长不入题，读者失去耐心——除非刻意用曲笔造势
- **段间无衔接**：各部分各说各话，靠序号硬拼
- **该直则曲**：上行文、汇报材料绕弯子，领导抓不住重点

## Worked Example
"借题发挥"的实例：2018年常德市委书记在德商恳谈会上的讲话，开篇宕开一笔拿《无问西东》《芳华》两部电影说事——清华校训"自强不息、厚德载物"引出常德人的精神气质，"一百个人有一百种芳华的解读"引出奋斗主题，随后亮出三层提纲："在奋斗的路上，我们有一路的故事/有清晰的目标/有担当的情怀"。借题的功能是造势与共情，提纲随即直笔收拢。另一例："归纳概括"开头——毛泽东《反对党八股》"我们也仿照八股文章的笔法来一个'八股'，以毒攻毒，就叫作八大罪状吧"——先把全文结晶摆出来，再分条阐释。

## Key Takeaways
1. 段首句是最低成本的提升点：每段第一句重写一遍，全文质感立刻不同
2. 17法按文种对号入座，不要每次都从"为了深入贯彻落实"开始
3. 九条逻辑逐条对照检查卡壳的段落，多数卡壳是逻辑错位不是文字问题
4. 检验写实：删掉名词解释和空转句，看还剩多少信息量
