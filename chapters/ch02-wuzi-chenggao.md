# Chapter 2: 五子成稿法——从接任务到交稿的全流程

## Core Idea
李永新的成稿流程五个动作环环相扣：磨刀子（储备）→定盘子（定调）→搭架子（结构）→敲键子（成文）→收果子（复盘）。出彩与否在动笔前就决定了大半。

## Frameworks Introduced
- **磨刀子**（平时储备五字诀）：
  - 要：主动调度，动态兜清情况，一调多用
  - 搜：四处寻媒介，储备素材与范文
  - 读：静心深阅读（详见 Ch08）
  - 合：分类萃合，随时揣摩备用
  - 练：建文稿模板，实战靶向储备
- **定盘子**（"干活不由东，累死也无功"）：动笔前敲定——解决什么问题、总体调子、分几部分、对成效如何评价、对形势怎么判断、篇幅多大、什么体例、何时交
  - When to use: 接到任务的第一反应，先敲盘子再动笔
  - How: 站领导角度研究意图（平时把握渠道：讲话批示、修改的花脸稿、关注的书报），站受众角度定切入
- **搭架子**：列提纲前重做两个深度研究——研究事（拉条子：梳理上情下情内情外情）+ 研究体（同题N种写法）
- **敲键子**（成文四步）：套摘堆砌（摘现成段落先摞到一起）→撮要归堆（合并同类项向主题聚敛）→通读权衡（查补缺漏增亮点）→捋顺打磨（看起承转合促气脉贯通）
- **收果子**：写完及时复盘，不忙时补课（泛读精读、更新模板），把经验固化为自己的写作体系

## Key Concepts
- **花脸稿**：领导改过的稿子，是研究领导思维与语言特点的一手材料
- **套改**：在本单位以往成熟定稿上更新，业务性材料的最快路径
- **"抄"的法则**：形神兼顾抄、上下结合抄、新旧对照抄，抄外拓思维、抄内遵惯性
- **一调多用**：一次调度调研的成果，同时服务于多个文种

## Mental Models
- 战时的从容来自平时的储备："闲时不闲沉淀储备，忙时不忙有粮不慌"
- 搭框架时"每列出一条，下面怎么写都非常清晰"才算成型，否则继续研究

## Anti-patterns
- **熬夜硬憋**：作者反复验证"边睡边酝酿"胜过熬夜奋战，框架在睡眠中自行迭代
- **为搭框架而搭框架**：框架必须长在情况研究上，不是格式填空
- **交稿即结束**：不复盘，同类任务永远从零开始

## Worked Example
作风建设动员部署会讲话稿复盘（两天任务）：连夜吃透上情（比对上级讲话、方案，弄清为什么整顿、整顿什么、怎么整顿）+ 吃透内情（领导专题会部署+半年来的论述+处室方案）。睡前反复在心里搭框架又推翻；第二天正式搭架时全部推翻前夜方案（"华而不实，经不起推敲"），靠白天调度调研把框架落到操作层面。最终提纲四部分：为什么（提高站位三段）→是什么（五个坚持整顿五类问题）→怎么办（五条举措）→怎么保障（组织领导四条）。作者点破：为什么/怎么办相对好写，出彩点在上情把握与可操作性。另一例：代拟省长讲话，通读省长一年政务新闻+历史论述+相关来件，"找到当省长的感觉"才动笔。

## Key Takeaways
1. 盘子不敲不动笔：谁讲、谁听、什么场合、什么调子，先答再写
2. 领导意图的最好教材是花脸稿和历史讲话，不是当场追问
3. 成文四步先摞后敛再打磨，比逐字从零写快且不散
4. 每稿必复盘，复盘产物是模板与提纲库，不是感想
