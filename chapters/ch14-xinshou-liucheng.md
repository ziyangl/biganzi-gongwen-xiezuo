# Chapter 14: 新手全流程——接到任务的第一小时到交稿

## Core Idea
把各书的动作压缩成一条新手可执行的时间线：先答三要素（字数、时间、目的），再定主旨与角度，然后套五子流程走完全程。公文写作的功夫大多在"写"之外。

## Frameworks Introduced
- **准备三要素**（王振第1章，接到任务先答三问）：
  - 字数：这篇材料多长？篇幅决定写法——字数多可旁征博引从容展开，字数少必须开门见山直击要点
  - 时间：什么时候要？倒排"构思→提纲→初稿→冷却→修改"的时间表
  - 目的：做什么用？目的决定角度，角度决定一切（谁看、解决什么问题）
- **公文写作基本流程**（陈征第一章）：确定公文主旨（鲜明、正确、着眼全局、集中一致、有预见性）→ 确定行文规则（对谁行文、用什么文种）→ 拟订提纲 → 明确结构和形式 → 收集材料 → 审改 → 审核与签发
- **主旨表达两法**（陈征）：直抒胸臆法（篇首直接亮明目的依据与要求）；段前摘要法（长材料每部分前摘要点，让"只扫标题"的领导也能拿到全部关键信息）
- **主旨五原则**（陈征）：鲜明（直白不含糊）、正确（与政策法规和上级意图一致）、着眼全局、集中一致（一文一事、防止"意多乱文"）、预见性
- **交稿有方**（李永新第8章第5节）：不仅要写好，更要汇报好——交稿时主动说明结构与取舍，帮领导快速抓到重点

## Key Concepts
- **一分钟定盘清单**（综合各书）：给谁看/听、解决什么问题、什么文种、多少字、何时要、什么调子
- **时间分配经验**（王振/李永新）：重要材料搜集素材可占近四分之三时间，成文反而短——"方案写作用四分之三时间搜集素材"的复盘结论
- **新手捷径**（李永新第3章）：本单位成熟稿子上套改；向身边笔杆子请教（"单位处处有老师"，带着稿子求提意见）

## Mental Models
- 三要素是需求的"合同"：字数、时间、目的谈不拢，后面全白干
- 新手先学"样子"再学"里子"：从标准与范文入手，最快建立专业感

## Anti-patterns
- **拿到任务就埋头写**：不问字数时间目的，方向错了推倒重来
- **主旨面面俱到**：贪大求全是公文大忌，"意多乱文"
- **交稿即失联**：不主动汇报思路，把理解成本全丢给领导

## Worked Example
"接到写作任务后的第一小时"清单（合成自王振三要素+陈征流程+李永新定盘子）：
1. 问清三要素：篇幅、时限、用途（用途含：给谁看、什么场合、期望解决什么）
2. 判断文种与角度：上行/下行/平行？褒扬/部署/商洽？（对应 Ch11 地图）
3. 翻模板库：本单位最近获批的同类定稿一份 + 条例对应条款
4. 快速调度：按上情（3–5份上级文件）、内情（本科室近期材料）、外情（兄弟单位同类稿）各取一撮
5. 一页纸提纲：主题一句 + 三个部分 + 每部分标注素材来源（概念型即可）
6. 与领导对表：五分钟汇报盘子——"我准备这样写，对不对路"——确认后再动笔
此后进入敲键子四步（Ch02），交稿时附三句话说明：结构逻辑、重点取舍、待领导定夺处。

## Key Takeaways
1. 第一小时不写字：把字数、时间、目的问清楚，比什么都要紧
2. 提纲先对表再动笔：领导点头的一页纸提纲，胜过三天返工
3. 长材料用段前摘要法：让扫读的领导也能拿到全部要点
4. 交稿即汇报：主动讲结构取舍，把修改引导到点上
