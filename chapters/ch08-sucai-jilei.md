# Chapter 8: 素材与积累——平时出力，战时出彩

## Core Idea
积累与写作如吸与呼：离开学习积累，写材料就是无源之水。素材要像管理者管团队一样管——分类、取舍、更新。

## Frameworks Introduced
- **素材三部曲**（薛贵辉）：收集 → 管理（"你不理材，材不理你"——8个维度给素材分类建档）→ 运用（"选材如征兵，用材如统兵"——5道关口选好用好素材）
- **文件的"6种打开方式"**（36堂课第12课）：读文件不是看一遍，按检视阅读、分析阅读等层次分目的读——同一份上级文件，学精神、学结构、学语言是三次不同读法
- **六摘读报法**（何剑文）：读党报党刊摘六类——摘标题框架、摘对仗排比、摘生动表述、摘党言党语、摘哲言金句、摘典故比喻
- **素材取舍三筛**（王振）：内容过时的不用、自相矛盾的不用、不合时宜的不用；运用时注意整体平衡、语言表述、专业术语
- **磨刀子五字诀的呼应**（李永新）：要（调度）、搜（寻媒介）、读（深阅读）、合（分类萃合）、练（建模板）——积累环节在成稿体系中的位置

## Key Concepts
- **"材"与"料"**（再强调）：收集的是材，入库前要加工成料——按口吻改写、存不同版本、分级打包
- **一调多用**：一次深度调度建立的多维素材库，能同时喂饱总结、汇报、讲话多个文种
- **定期整理习惯**（王振）：素材库不整理就会烂尾，定期删旧补新

## Mental Models
- 素材库是弹药库不是仓库：入箱时按用途分装，战时直接取用
- "写作没有白读的书"：读的时候不明确用途，用的时候才想起来没存——阅读必须带摘录动作

## Anti-patterns
- **只存不读**：收藏夹吃灰，存了等于没存
- **只摘句子不摘框架**：金句易得，标题框架与结构套路才是高价值积累
- **战时才找素材**：临时抱佛脚的调度永远不如平时兜清的全面

## Worked Example
六摘读报法的操作实例：读一份省级党报头版，摘标题框架——"砥砺前行，全省工业经济成效明显；认清形势，转型发展任重道远；稳中求进，全力打好攻坚战"（三段式标题+四字引导语），存入"标题框架"库；摘对仗排比——"惜时如金、奋发如木、包容如水、激情如火、奉献如土"（五行比喻式排比），存入"对仗排比"库；摘党言党语——最新提法的标准表述。三本台账分开维护，写总结翻第一本、写讲话翻第二本、写理论文章翻第三本。这就是"合——分类萃与合，随时揣摩备用"的具体做法。

## Key Takeaways
1. 读文件带着三个目的各读一遍：学精神、学结构、学语言
2. 摘录必须当日归档分类，否则积累等于流水
3. 素材入库前按自己口吻改写并存多版本
4. 每周固定留白做"素材盘点"：删过时、补新案、调分类
