# Chapter 9: 修改与瘦身——热写冷改

## Core Idea
"开始处理材料时要冷，写的时候要热，在修改时还要冷"（艾芜）。修改不是补救，是写作的另一半；硬伤会致命，软伤毁质感，瘦身出骨感。

## Frameworks Introduced
- **修改三部曲**（薛贵辉36堂课）：如何看待修改（认识）→ "数论"改稿技巧（改稿要心中有数——知道删什么比知道写什么更重要）→ 审稿的"几下子"（审稿人视角）
- **硬伤4症状·4病因·3防治**（36堂课第21课）：硬伤是事实、数据、政策引用、格式规范层面的错误——致命且可防（对照原文核、交叉验证、按标准查格式）
- **软伤15症状·4防治**（36堂课第22课）：软伤是逻辑不清、层次混乱、语言平淡、观点悬浮等质量类问题——靠通读、朗读、换位读排查
- **瘦身方法论**（36堂课第23–25课）："减肥"不带偏见（该删则删）、切莫头痛医头（篇幅问题常是结构问题的表象）、心中有尺度笔下才有限度（篇幅控制论）
- **理面子**（何剑文五子棋第五子）：修改美容是成稿的固定工序，不是可选动作
- **审改四查**（陈征）：主旨内容（政策对不对）、材料事实（数据实不实）、结构格式（体例顺不顺）、文字语气（表述准不准、口吻对不对）

## Key Concepts
- **热写冷改**：趁热打铁写初稿，冷却后以读者视角改——两个状态不要混
- **硬伤 vs 软伤**：硬伤关乎真实性与规范性（零容忍），软伤关乎表达质量（持续打磨）
- **"删节改善作品"**（托尔斯泰）：任何出色的补充也不能像删节那样大大改善作品

## Mental Models
- 修改是把作品当成不是自己的：从别人的角度吹毛求疵
- 篇幅超标先查结构：冗长的根源常是结构重复，不是文字啰嗦

## Anti-patterns
- **写完即交**：跳过冷却期，作者视角遮蔽读者视角
- **只查错字不改逻辑**：软伤不除，稿子永远"平淡无奇"
- **心疼删掉的段落**：为舍不得的句子保住冗余，是修改最常见的败因

## Worked Example
篇幅"系统论"的复盘逻辑（36堂课第24课）：某汇报稿超字数30%，作者初稿的反应是逐句压字数（头痛医头），改了两遍收效甚微；退一步查结构，发现"做法"部分三条中有两条实为同一工作的两个阶段——合并后删去重复背景，篇幅自然回落，逻辑反而更顺。配套动作：先按"硬伤清单"核事实与数据，再按"软伤15症状"过逻辑与语言，最后做瘦身三问——这段删掉全文还成立吗？这句有没有更短的等价说法？这个层次与相邻层次是否重复？三问全过后，"骨感"自然出现。

## Key Takeaways
1. 初稿写完至少冷却一轮（睡前放、隔天改）再交
2. 硬伤零容忍：数据、引文、格式逐项对照源头核验
3. 篇幅问题先查结构重复，再动文字
4. 修改三问（删掉成立吗/有更短说法吗/层次重复吗）每稿过一遍
