# biganzi-gongwen-xiezuo

公文写作 agent skill。由 8 本中文公文写作书提炼合成（book-to-skill 流程，DEPTH=study）：

- 薛贵辉《笔杆子修炼36堂课》《公文写作32讲》《公文写作精进-28个锦囊》
- 李永新《笔杆子是怎样炼成的：公文写作实战》、朱立东/李永新《笔杆子是怎样炼成的2：公文写作模板》
- 何剑文《公文写作思维方法与实战》
- 王振《公文写作实战秘籍》
- 陈征《手把手教你公文写作》

## 安装

```bash
npx skills add ziyangl/biganzi-gongwen-xiezuo
```

或手动：克隆后把目录链接/拷贝到 `~/.agents/skills/`（Cursor、Claude Code 等支持 agents skills 的客户端均可识别）。

## 内容

- `SKILL.md` — 核心框架速览 + 章节索引 + 主题索引（约 1.7k token）
- `chapters/ch01–ch14` — 14 个主题章节，每章含核心观点、框架、反模式、实例（600–800 token/章）
- `glossary.md` — 术语表
- `patterns.md` — 写法模式库（标题、开头、结构、语言）
- `cheatsheet.md` — 速查决策表（文种选择、修改检查单、段位自评）

## 覆盖的方法论

- 何剑文"五子棋"写作法（找料子→梳辫子→戴帽子→填肚子→理面子）
- 李永新"五子"工作法（磨刀子→定盘子→搭架子→敲键子→收果子）、四个深度研究
- 薛贵辉写作函数 y=f(x)、9 大思维、谋篇布局五步、语言 7 种味道、开头引题 17 法、笔杆子 4 段位
- 王振任务三要素（字数/时间/目的）

## 边界

覆盖以这 8 本书为限。行文格式以《党政机关公文处理工作条例》（中办发〔2012〕14 号）与 GB/T 9704—2012 为准，书籍内容与其冲突时以条例国标为准。
